Tips

Type a known task name to place it as a budgeted block; type any other name to drop in a one-off meeting (no hour budget). Days: every day (Mon–Sat), mon-fri, tue and thu, weekends (Sat). Weeks: add this week, whole masterplan, or a range like weeks 38-51. Start with delete to bulk-remove matching blocks (e.g. delete EGE:EGE-Teaching tue weeks 38-51 3pm-6pm). Drag either end of a block to resize; tap a block for nudge buttons. The 🗒 button shows/hides a sticky note you can drag anywhere (Ctrl+B bold, Ctrl+I italic, Ctrl+H pink).
